# 학급 출석부

교사가 태블릿에서 학생 출결, 수업 태도, 자리 배치를 관리하는 정적 웹앱입니다.

## 실행

Node.js가 설치된 환경에서 다음 명령을 실행합니다.

```powershell
node server.js
```

브라우저에서 [http://localhost:8080](http://localhost:8080)을 엽니다.

## 주요 기능

- 학급 생성·삭제, 학생 명단 일괄 붙여넣기(5자리 학번, 이름)
- 6 × 6 교실 자리 배치와 랜덤 배치, 빈자리 사전 선택, 학생·빈자리 교환
- 모둠(4인 1모둠), 분단(2열 3분단), 시험(6 × 6) 대형
- 교사·학생 시점 전환 및 전체 화면 수업 화면
- 출석·결석·지각·조퇴 기록
  - 상태 미선택 시 학생 클릭마다 출석 → 결석 → 지각 → 조퇴 순환
  - 상태 버튼 선택 시 여러 학생에게 같은 상태를 연속 적용
- 학습 태도 점수(1~5점)와 메모 기록
- 기간별 학생 출결·태도 누적 조회와 날짜별 상세 기록 확인
- 1주일·2주일·1달·1학기 초(3월 2일)·2학기 초(8월 16일) 빠른 기간 설정
- 설정 기간의 학생별 날짜·출결·태도 점수·메모를 Excel(.xlsx) 파일로 내보내기
- 학급, 학생, 자리 배치, 출결, 태도 기록 전체를 JSON 텍스트 파일로 내려받기·불러오기

## 데이터 저장

Firebase를 연결하지 않은 경우 데이터는 이 브라우저의 로컬 저장소에 보관됩니다.

Firebase 연결 후 `웹에 저장하기`를 누르면 학급 데이터가 Firestore의 `classes/{학급ID}` 문서에 저장됩니다. 실제 학교 환경에서는 Firebase Authentication과 교사 전용 Firestore 규칙을 설정하세요.

## JSON 백업 형식

`내려받기`는 `.json.txt` 파일에 다음 정보를 저장합니다.

- 학급명과 자리 대형
- 학생 ID, 5자리 학번, 이름, 배정 자리
- 날짜별 출결 기록
- 날짜별 수업 태도 점수, 메모, 기록 시각

백업 파일은 `불러오기`로 복원할 수 있습니다.

`엑셀로 저장`은 선택 기간의 기록을 학생별로 정렬해 `기간 요약`과 `학생별 상세 기록` 시트에 저장합니다.
## 현재 저장 방식

- 상단 `저장하기`는 현재 선택한 **한 학급**의 학생, 자리 배치, 날짜별 출결·태도 기록, 공통 태도 예시 문장을 JSON 형식의 `.txt` 파일로 저장합니다.
- `불러오기`는 이 파일을 현재 선택한 학급으로 복원합니다.
- `내려받기`는 현재 학급의 전체 기록을 백업 파일로 내려받습니다.
- `웹에 저장하기`는 Firebase를 연결했을 때 사용할 수 있으며, 현재는 로컬 파일 저장 방식만으로도 사용할 수 있습니다.

## 수업 중 기록

- 날짜가 바뀌면 그 날짜의 출석 기록이 새로 시작되며, 모든 학생은 기본값으로 `출석`으로 표시됩니다. 결석·지각·조퇴처럼 변경한 상태만 별도로 기록됩니다.
- 학습 태도는 `전원 +1점`, `+1점`, `-1점`, `전원 -1점`으로 기록할 수 있습니다. 학생을 직접 선택했을 때는 해당 학생의 당일 점수·메모 내역을 확인할 수 있습니다.
- 점수 기록 직후에는 학생 카드 강조와 완료 알림이 표시됩니다.
- 태도 메모의 예시 문장은 모든 학급에서 공통으로 사용하며, 기록 창의 `예시 문장 관리`에서 추가·삭제할 수 있습니다.

## 전체 화면

전체 화면에서는 안내 헤더를 숨기고 자리배치와 학생 카드를 확대해 수업 중 태블릿 화면에서 바로 조작할 수 있도록 구성했습니다.
