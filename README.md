# 학급 출석부

교사가 태블릿에서 학생 출결, 수업 태도, 자리 배치를 관리하는 정적 웹앱입니다.

## 사용

### 웹앱 사용 (권장)

별도 설치나 서버 실행 없이 [학급 출석부 웹앱](https://class-attendance-98a88.web.app)을 열어 사용합니다. 첫 화면에서 Google 교사 계정으로 로그인하면 해당 교사의 학급 데이터를 자동으로 불러옵니다.

### 로컬 파일을 바로 열기

개발 또는 화면 확인 목적으로 `index.html` 파일을 더블클릭해 브라우저에서 바로 열 수 있습니다. 교사 로그인과 Firebase 동기화에는 인터넷 연결이 필요합니다.

### 엑셀 다운로드를 포함한 로컬 사용

현재 배포된 웹앱은 정적 Firebase Hosting으로 제공되므로 `.xlsx` 생성 기능은 포함하지 않습니다. `엑셀로 저장` 기능까지 사용하려면 프로젝트 폴더에서 Node.js 로컬 서버를 실행합니다.

```powershell
node server.js
```

그 뒤 브라우저에서 [http://localhost:8080](http://localhost:8080)을 엽니다. 서버 없이 파일을 직접 열었거나 배포된 웹앱에서 `엑셀로 저장`을 누르면 로컬 서버 실행 방법이 안내됩니다.

## 주요 기능

- 학급 생성·삭제, 학생 명단 일괄 붙여넣기(5자리 학번, 이름)
  - `전체 학생 삭제`로 현재 학급의 학생 명단, 자리 배정, 학생별 출결·태도 기록을 한 번에 삭제
- 6 × 6 교실 자리 배치와 랜덤 배치, 빈자리 사전 선택, 학생·빈자리 교환
- 모둠(4인 1모둠), 분단(2열 3분단), 시험(6 × 6) 대형
- 교사 대시보드와 수업 중 학습 태도 화면에서의 선생님·학생 시점 전환
  - 학생 시점에서는 교탁이 상단에 표시되고, 자리의 앞·뒤 순서는 학생 기준으로 전환하며 학생 이름은 정상 방향으로 표시
- 태블릿 가로·세로 화면에서 사용할 수 있는 전체 화면 수업 화면
  - 전체 화면에서는 수업 안내 헤더와 수업 진도 패널을 숨기고 자리배치 조작 영역만 표시
  - 최신 브라우저와 구형 iPad Safari의 WebKit 전체 화면·대체 전체 화면 모드를 함께 지원
- `교사 대시보드`·`수업 중 학습 태도`·`학생별 누적 기록` 화면 전환
- 관리자 교사에게만 노출되는 `관리자 대시보드`
  - Google 로그인으로 생성된 교사 계정 조회
  - 교사별 소속 학교·담당 과목·관리자 권한 관리
- 출석·결석·지각·조퇴 기록
  - 상태 미선택 시 학생 클릭마다 출석 → 결석 → 지각 → 조퇴 순환
  - 상태 버튼 선택 시 여러 학생에게 같은 상태를 연속 적용
  - `출결 저장` 버튼을 눌러 해당 날짜의 출결을 확정
- 학습 태도 `+1점`·`-1점`과 메모 기록
  - 전원 일괄 기록 또는 여러 학생을 순서대로 선택해 같은 기록 적용
  - 자주 쓰는 태도 메모 예시 문장 추가·삭제
- 선택 학급의 날짜별 수업 진도 메모
  - 날짜·요일, 교시, 차시, 진도 기록
  - 이전 버튼은 출결 저장이 완료된 날짜만 표시하고, 다음 버튼은 다음 날짜를 표시
- 별도 화면에서 기간별 학생 출결·태도 누적 조회와 날짜별 상세 기록 확인
  - 잘못 입력한 출결 상태 또는 태도 기록을 개별 삭제
- 1주일·2주일·1달·1학기 초(3월 2일)·2학기 초(8월 16일) 빠른 기간 설정
- 설정 기간의 학생별 날짜·출결·태도 점수·메모를 Excel(.xlsx) 파일로 내보내기
- 학급, 학생, 자리 배치, 출결, 태도 기록 전체를 JSON 텍스트 파일로 내려받기·불러오기

## 데이터 저장

로그인 전에는 앱 본문이 표시되지 않습니다. 로그인한 교사별로 브라우저 로컬 저장소를 분리해 사용하므로 다른 교사의 로컬 정보가 보이지 않습니다.

Google 교사 로그인 후에는 Firestore에서 해당 교사가 소유한 학급 데이터를 자동으로 불러옵니다. 학급·학생·자리·출결·태도·진도 변경은 약 0.7초 뒤 Firestore에 자동 저장됩니다. Firestore 규칙은 일반 교사가 본인의 학급에만 접근하도록 제한합니다.

여러 기기에서 같은 학급을 동시에 수정하는 충돌 병합 기능은 아직 없으므로, 마지막 자동 저장 내용이 기준이 될 수 있습니다.

### 인증과 관리자 설정

- Firebase Authentication의 **Google** 로그인 제공업체를 사용합니다.
- Firebase 콘솔에서 **Authentication → Sign-in method → Google**을 사용 설정해야 합니다.
- 최초 관리자는 Google 로그인 후 Firestore의 `users/{teacherUid}` 문서에서 `isAdmin`을 Boolean `true`로 한 번 지정합니다.
- 관리자만 모든 교사 프로필을 읽고, 소속·과목·관리자 권한을 수정할 수 있습니다. 관리자도 다른 교사의 학급·학생·출결 데이터에는 접근할 수 없습니다.

### Firebase 데이터 구조

```text
users/{teacherUid}
classes/{classId}
classes/{classId}/students/{studentId}
classes/{classId}/lessons/{YYYY-MM-DD}
classes/{classId}/layouts/current
classes/{classId}/settings/general
classes/{classId}/auditLogs/{logId}
```

- `users`에는 교사 UID, 이메일, 프로필·권한 기본값을 저장합니다.
- `classes`에는 학급명, 담당 교사 UID, 생성·수정·삭제 시각을 저장합니다.
- `students`에는 학번, 이름, 자리 번호, 재학 상태를 저장합니다.
- `lessons`에는 날짜별 출결 저장 여부, 학생별 출결, 태도 점수·메모, 교시·차시·진도를 저장합니다.
- `layouts`에는 자리 대형, 고정 빈자리, 학생별 자리 정보를 저장합니다.
- `settings`에는 공통 태도 메모 예시 문장을 저장하고, `auditLogs`에는 웹 저장과 삭제 관련 이력을 남깁니다.
- 학급과 수업 기록 삭제는 `deletedAt`, `deletedBy`를 남기는 복구 가능한 소프트 삭제 방식입니다.

## JSON 백업 형식

`파일로 저장한 후 내려받기`는 `.json.txt` 파일에 다음 정보를 저장합니다.

- 학급명과 자리 대형
- 학생 ID, 5자리 학번, 이름, 배정 자리
- 날짜별 출결 기록
- 날짜별 수업 태도 점수, 메모, 기록 시각
- 날짜별 수업 진도(교시, 차시, 진도)

백업 파일은 `파일에서 불러오기`로 현재 선택한 학급에 복원할 수 있습니다.

`엑셀로 저장`은 선택 기간의 기록을 학생별로 정렬해 `기간 요약`과 `학생별 상세 기록` 시트에 저장합니다.
## 파일 백업

- `파일에서 불러오기`는 JSON 백업 파일을 현재 선택한 학급으로 복원합니다.
- `파일로 저장한 후 내려받기`는 현재 학급의 전체 기록을 JSON 백업 파일로 저장하고 바로 내려받습니다.
- Firebase 자동 저장과 별도로 파일 백업을 만들 때 사용합니다.

## 배포

Firebase Hosting은 정적 파일을 배포합니다. GitHub의 `main` 브랜치에 푸시하면 GitHub Actions가 Workload Identity Federation(OIDC)으로 Google Cloud에 인증한 뒤 Firebase Hosting과 Firestore 규칙을 자동 배포합니다.

- 배포 워크플로: `.github/workflows/firebase-deploy.yml`
- 공개 주소: <https://class-attendance-98a88.web.app>

`엑셀로 저장`은 Firebase Hosting에서 실행되지 않습니다. 이 기능은 `server.js`의 `/export.xlsx` 처리 경로를 사용하므로, Node.js가 설치된 로컬 환경에서 `node server.js`를 실행한 뒤 `http://localhost:8080`으로 접속해야 합니다.

## 수업 중 기록

- 날짜가 바뀌면 그 날짜의 출석 기록이 새로 시작되며, 모든 학생은 기본값으로 `출석`으로 표시됩니다. 결석·지각·조퇴처럼 변경한 상태만 별도로 기록됩니다.
- 출결 상태를 입력한 뒤 `출결 저장`을 누르면 해당 날짜가 확정되며, 수업 진도의 이전 날짜 탐색 대상이 됩니다.
- 학습 태도는 `전원 +1점`, `+1점`, `-1점`, `전원 -1점`으로 기록할 수 있습니다. 학생을 직접 선택했을 때는 해당 학생의 당일 점수·메모 내역을 확인할 수 있습니다.
- 점수 기록 직후에는 학생 카드 강조와 완료 알림이 표시됩니다.
- 태도 메모의 예시 문장은 모든 학급에서 공통으로 사용하며, 기록 창의 `예시 문장 관리`에서 추가·삭제할 수 있습니다.

## 전체 화면

전체 화면에서는 안내 헤더와 수업 진도 패널을 숨기고, 자리배치와 학생 카드를 확대해 수업 중 태블릿 화면에서 바로 조작할 수 있도록 구성했습니다. 최신 전체 화면 API를 지원하지 않는 구형 iPad Safari에서는 앱 내부의 대체 전체 화면 모드와 WebKit 전용 규칙을 사용해 동일하게 표시합니다.

## 최근 수정

- 구형 iPad Safari에서 기본 `dialog.close()`를 지원하지 않아도 학습 태도 기록 저장 후 창이 정상적으로 닫히도록 호환 처리를 추가했습니다.
- 같은 교사 계정으로 여러 기기를 사용하면 Firestore 실시간 동기화가 다른 기기의 저장 완료를 감지해 학급·학생·자리·출결·태도·진도를 자동으로 반영합니다. 같은 내용을 동시에 수정한 경우 마지막으로 저장된 변경이 적용됩니다.
- 수업 진도 패널의 날짜·요일 옆에 달력 버튼을 추가해 날짜 선택기를 바로 열 수 있습니다.
- 날짜를 바꾸면 진도 저장 버튼과 출결 저장 버튼이 새 날짜의 저장 상태에 맞춰 갱신됩니다.
- 새 학급 만들기 창을 안내 문구, 입력 라벨, 포커스 상태를 갖춘 모달 디자인으로 개선했습니다.
- 전체 학생 기록 또는 특정 날짜의 진도·기록을 삭제하면 Firebase의 기존 수업 문서도 소프트 삭제하여, 다른 기기나 재로그인 후 삭제 기록이 다시 나타나지 않습니다.
- Firebase 자동 저장 중 변경이 발생하면 저장 완료 후 한 번 더 저장해 빠른 연속 입력도 누락되지 않도록 했습니다.
- 학습 태도 모드에서 학생 카드를 누르면 전체 화면 여부와 관계없이 개인 학습 태도 기록 창이 표시됩니다.
- 구형 iPad Safari처럼 기본 `<dialog>` 표시가 제한된 브라우저에서도 기록 창을 화면 중앙의 불투명한 모달로 표시합니다.
- 학생별 누적 기록에서는 학생 카드별 `학생 기록 전체 삭제`와 조회 영역의 `전체 학생 기록 전체 삭제`를 제공합니다.
- 학습 태도 모드의 상단 점수 선택과 개인 기록 창에 `0점` 메모 기록을 제공합니다. 0점 기록은 태도 평균에 반영되지 않고 `메모`로 표시됩니다.
- 수업 진도 패널은 선택한 날짜를 `YYYY.MM.DD (요일)` 형식으로 표시하며, 표시 영역을 눌러 날짜를 바꿀 수 있습니다.
- 새 학급을 만들면 지연 자동 저장을 기다리지 않고 Firebase에 즉시 저장하므로, 생성 직후 학급을 전환하거나 페이지를 닫아도 웹 저장본에서 누락되지 않습니다.
- 자동 저장은 Firestore 보안 규칙의 일괄 요청 제한을 고려해 최대 10개 문서 단위로 나누어 처리하며, 실패 시 화면 상태 표시줄에 Firebase 오류 코드가 나타납니다.
- 새 학급은 부모 학급 문서를 먼저 만든 뒤 학생·자리·수업 기록 하위 데이터를 저장하여 `permission-denied` 오류 없이 웹에 저장합니다.
- 자동 저장에서는 교사 프로필 문서를 다시 쓰지 않아, 기존 프로필의 권한 필드 차이로 학급 저장 전체가 거부되는 문제를 방지합니다.
- 웹에 아직 없는 새 학급은 사전 읽기 없이 부모 문서를 먼저 생성하므로, Firestore 규칙이 없는 문서 읽기를 거부해 발생하던 `permission-denied` 오류를 방지합니다.
- Firebase에는 Google 교사 계정(UID), 학급 정보, 학생 명단과 자리, 날짜별 출결·교시·차시·진도·학습 태도 기록, 자리 배치와 공통 설정이 학급별 하위 컬렉션 구조로 저장됩니다.
